# SAP Ordem de Venda RAP

Projeto de gestão de ordens de venda desenvolvido com ABAP RESTful Application Programming Model (RAP), CDS Views, OData V4 e SAP Fiori Elements.

## Ambiente
- SAP S/4HANA 2023
- ABAP Platform 2023
- Eclipse ADT
- SAP RAP
- OData V4
- SAP Fiori Elements

## Objetivo
Demonstrar o desenvolvimento de uma aplicação empresarial utilizando o modelo transacional RAP, incluindo cabeçalho de ordem, itens, regras de negócio, cálculos automáticos e controle de status.
